# 개인 로컬 경로 하드코딩 정리

## 대상 경로

기존 일부 사운드 생성 스크립트에 아래 개인 로컬 경로가 직접 들어가 있었다.

```text
/Users/gimseongjun/Desktop/DeadZone
```

이 경로는 해당 사용자의 Mac에서만 동작하므로, 다른 환경에서 스크립트를 실행하면 사운드 파일 생성 위치가 틀어지거나 실패할 수 있다.

## 수정된 파일

| 파일 | 기존 문제 | 수정 내용 |
| --- | --- | --- |
| `src/generate_siren.py` | `/Users/gimseongjun/Desktop/DeadZone/assets/sounds/siren.wav`에 직접 저장 | 현재 파일 위치 기준 repo 루트를 계산해 `assets/sounds/siren.wav`에 저장 |
| `assets/sounds/generate_combat_sounds.py` | `shoot.wav`, `swing.wav`, `hit.wav`, `siren.wav` 출력 경로가 개인 절대경로 | 스크립트가 있는 `assets/sounds` 폴더 기준 상대경로로 저장 |
| `assets/sounds/generate_sound.py` | `footstep.wav` 출력 경로가 개인 절대경로 | 스크립트가 있는 `assets/sounds` 폴더 기준 상대경로로 저장 |

## GitHub 반영 요청 문구 예시

사운드 생성 스크립트에 개인 Mac 절대경로(`/Users/gimseongjun/Desktop/DeadZone`)가 하드코딩되어 있어 다른 PC에서 실행할 수 없는 문제가 있었습니다.  
이를 repo 기준 상대경로로 변경했으니 GitHub에 반영 부탁드립니다.

## 확인 방법

아래 명령으로 개인 경로가 남아있는지 확인할 수 있다.

```bash
rg -n "/Users/gimseongjun|/Users/.*/DeadZone" . -g '!build/**' -g '!.git/**'
```

현재 코드와 스크립트에서는 해당 개인 경로가 제거되었다.
